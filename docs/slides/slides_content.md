## Slide 2｜平台概览

**PRISM**（Policy Review and Investment Screening Mechanisms）

38 个国家 × 2007—2023 年的 FDI 审查机制逐年编码数据

**什么是 FDI 审查？**
政府对入境外资进行审查、附条件批准或否决的制度安排，依据为国家安全、公共秩序或战略经济利益。2015 年后设立正式机制的国家快速增加，2019 年 EU FDI 审查条例与新冠疫情进一步加速这一趋势。

| 维度 | 内容 |
|------|------|
| 时序记录 | 650 条国家-年数据 |
| 程序指标 | 13 项二元权力 + 4 项量化字段 |
| 立法文书 | 143 项；立法事件 230 条 |
| 政策原文 | 141 份（PDF + HTML） |
| 行业追踪 | 36 个细分类 + 8 个汇总类 |
| 国家分组 | OECD · EU/EEA · 五眼 |

## Slide 4｜出发点与工具

**出发点**
PRISM ISM Dataset 存在 Excel 里，只有自己能看。目标是把它变成任何人可以通过网址交互探索的平台。

**作者背景**
有 Python 基础；无 HTML / CSS / JavaScript 经验，无网站部署经验。

**工具选择**

**Claude Code**（Anthropic 官方 CLI 编程助手）

- 跨文件理解整个代码库上下文
- 用中文描述需求 → Claude 修改文件 → 浏览器验证效果

**技术选型**

## Slide 5｜第一步：数据准备

**任务**：将 Excel 数据集转换为前端可读取的 JSON 文件。

AI 生成 `preprocess.py`（628 行），处理：

- 缺失值填充与字段名标准化
- threshold 字段格式归一化（"25%" 与 0.25 两种格式统一处理）
- EU/EEA 成员资格判断
- 141 份政策文件提取（扫描版 PDF 用 OCR，损坏文件逐类处理）

**输出：7 个 JSON 文件**

| 文件 | 内容 |
|------|------|
| `timeseries.json` | 650 条国家-年记录 |
| `events.json` | 143 项立法事件 |
| `changes.json` | 230 条立法变动 |
| `policy_texts.json` | 141 份政策原文 |
| `search_index.json` | 全文检索索引 |

**人工完成的环节**：逐字段核查业务含义是否被正确解析，纠正了若干字段理解错误——数据的业务含义只有研究者本人能判断。

## Slide 7｜第三步：实用工具

**Deal Screener**
- 需求由我提出；AI 设计判断逻辑
- 逻辑基于：覆盖范围 + 门槛比较 + 强制/自愿申报 + EU/非 EU 差异

## Slide 8｜第四步：问题排查与部署

**主要问题类型**

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 网页打开空白 | 浏览器跨域限制 `file://` 协议 | 启动本地 HTTP 服务器 |
| 2024 年数据骤降 | 数据集截至 2023，图表默认展示到 2024 | 全局修改年份上限，清理残留引用 |
| 图表交互冲突 | 多个 Tab 共享状态导致联动异常 | 逐处隔离事件监听器 |

约 21 次提交中，一半用于修 Bug。

**部署流程**
1. `rebundle.py`：将所有 JS / CSS / 数据 gzip 压缩后 base64 编码嵌入 `index.html`（2.5 MB）
2. `update.bat`：双击运行，填写描述，自动打包并推送至 GitHub
3. GitHub Pages 约 1 分钟后自动更新

**上线后修复**：补传 141 份政策文件（首次未随代码提交导致全部 404）
